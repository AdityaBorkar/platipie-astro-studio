# GLOSSARY.md

| Term                          | Definition                                                                                                                                                                                                                                  |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Project root (`PROJECT_PATH`) | Absolute path to the project checkout being managed (falls back to cwd). Server-only; never sent to the frontend. The CMS never owns content; it reads/writes under this root.                                                              |
| Collection                    | A named content set from Astro Content Layer (`projects`, `blog`, `clients`, `mockups`, `testimonials`), each backed by `glob` (files) or `file` (JSON) loaders.                                                                            |
| Unified editor                | The single CMS editing screen with a Markdown ⇄ Visual toggle, frontmatter form, preview panes, and SEO sidebar sharing one save pipeline.                                                                                                  |
| Visual mode                   | Local WYSIWYG editing (TipTap/Milkdown) styled like Astro. Distinct from faithful preview, which is a read-only Astro iframe.                                                                                                               |
| Faithful preview              | Read-only iframe rendering `${ASTRO_URL}/<preview-path>` from the running Astro dev server. Absent when `ASTRO_URL` is unset.                                                                                                               |
| WordPress-parity set          | Canonical publishing/SEO fields: slug, excerpt, status, publishDate, modifiedDate, author, categories, tags, featuredImage, canonicalUrl, metaTitle, metaDescription, keywords, ogImage, ogType, twitterCard, noindex/nofollow, schemaType. |
| Status                        | `draft \| published \| scheduled`. V1 persists it as frontmatter only; visibility filtering and scheduling behavior live in the Astro site, not the CMS.                                                                                    |
| Filename-is-slug              | Rule that the file stem equals the slug; editing slug renames the file.                                                                                                                                                                     |
| Schema extension              | Additive, optional-only widening of `content.config.ts` Zod schemas so WP-parity frontmatter validates and survives Astro builds. Never narrows existing rules.                                                                             |
| Drift                         | Content or schema reality differing from the registered Zod model (e.g. testimonials `project` key, template oddity). Surfaced, never silently dropped.                                                                                     |
| Trash                         | Soft-delete area (`.cms-trash/`) retaining deleted files/rows for `TRASH_TTL_DAYS` before hard expiry.                                                                                                                                      |
| Workspace                     | The project checkout at `PROJECT_PATH` (or cwd), represented in the app rail by its project name (`package.json`) and current git branch.                                                                                                   |
| App rail                      | The fixed 264px left sidebar: workspace identity, nav map, primary navigation, and persisted display toggles. It becomes a drawer below `lg`.                                                                                               |
| Page inventory                | The routable files under `src/pages` (`.astro`, `.md`, `.mdx`), excluding private `_` files, API routes, and error pages; surfaced on `/website`.                                                                                           |
| UI preference                 | A `localStorage` flag (`showPagesInSidebar`, `showWebsiteMeta`, `showCms`, `showContentSeo`) that shows or hides a rail/tree without changing content.                                                                                      |
